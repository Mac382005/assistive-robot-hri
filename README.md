# HRI Socially Assistive Robot

A tabletop socially assistive robot prototype designed to support older adults with routine reminders such as medication, hydration, meals and appointments.

## Software Stack

- Python
- Flask
- HTML / CSS / JavaScript
- SQLite
- APScheduler
- Raspberry Pi
- Touchscreen interface

## Main Features

- Routine reminders
- Touchscreen acknowledgement
- Social robot interface
- Response-time measurement
- Experimental social-cue conditions
- Local SQLite data storage
- Future Raspberry Pi hardware integration

## Development

The application is initially developed and tested on Windows using mock hardware. It will later be deployed to a Raspberry Pi with the touchscreen, LEDs, sensors, speaker and servos.
