HRI ASSISTIVE ROBOT — VERSION 1
================================

COPY THESE FILES INTO:
C:\Users\MAC\Documents\HRI\assistive_robot

The ZIP deliberately does NOT contain .venv, .git, or a database file.
Keep your existing .venv and Git repository.

1) In VS Code, open:
   C:\Users\MAC\Documents\HRI\assistive_robot

2) Open Terminal and activate the environment:
   .venv\Scripts\Activate.ps1

3) Make sure dependencies are installed:
   pip install -r requirements.txt

4) Run automated checks:
   python -m unittest discover -s tests -v

5) Start the robot software:
   python app.py

6) Open this in Chrome/Edge:
   http://127.0.0.1:5000

7) Click the gear icon in the top-right corner.
   - Enter Participant ID
   - Optional display name
   - Choose LOW or HIGH
   - Choose reminder type
   - Click Trigger test reminder

8) Press OK on the reminder screen.
   The response time is stored automatically in:
   data\robot.db

9) Open the developer panel again to see recent trials.
   Use Export CSV to download all trials.

10) Stop the server with:
   Ctrl + C

11) Save this version in Git:
   git add .
   git commit -m "Add Version 1 robot UI and experiment workflow"

IMPORTANT:
- Hardware actions are MOCKED on Windows. Look at the VS Code terminal when testing them.
- Browser speech is only a development fallback. Use fixed WAV files before formal HRI testing.
